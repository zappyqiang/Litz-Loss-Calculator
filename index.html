Model and checks

Equations

Each strand has radius r and carries I/N. With γ = (1+j)/δ and δ = √(2ρ / ωμ₀), using modified Bessel functions I₀ and I₁:

Rdc = ρ·l / (N·π·r²) F_skin = Re[ γr·I₀(γr) / (2·I₁(γr)) ] P_skin = F_skin · Rdc · I² H_i² = I² / (8π²·R_b²) (mean square, rms) P_prox = N · l · k_p(f) · H_i² Rac = (P_skin + P_prox) / I²

k_p is the exact loss per metre in one round strand placed in a uniform transverse field, in W/m per (A/m)² rms. It tends to σ·π·ω²·μ₀²·r⁴/4 at low frequency. R_b is the bundle radius, and the current is assumed uniform over it, which is what a well-transposed litz wire does.

Not included: loss from fields outside the bundle (neighbouring turns, air gaps, cores), uneven current sharing, and insulation or serving losses.

Check against 2D finite elements

A 19-strand bundle gives the same picture (+0.04 % at 100 kHz, +3.6 % at 1 MHz). Above d/δ of about 2 the strands start to screen each other, which the uniform-field model ignores, so it overestimates loss there. That is the shaded zone on the chart.
